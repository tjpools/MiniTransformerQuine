# MiniTransformerQuine

MiniTransformerQuine is an educational repository for studying transformer logic as executable structure. It combines language-level implementations with reverse-engineering and analysis artifacts, so readers can approach the transformer as code, as mathematics, and as a machine.

- `languages/` contains executable implementations and language-specific project surfaces.
- `analysis/` contains reverse-engineering and inspection material used to study emitted binaries and structure.
